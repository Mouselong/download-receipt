# Security and privacy

Download Receipt stores file paths, source URLs, notes, and fingerprints only
on the local computer. Version 0.2.0 has no telemetry, account, or network API.

Source URLs can contain private tokens. Do not publish your local database or
paste full URLs into public bug reports without reviewing them first.

To report a vulnerability, open a GitHub security advisory instead of a public
issue when the repository is published.
